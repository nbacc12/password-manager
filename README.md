# Password Manager

This is a local, GUI-based application built with Python. It allows users to securely store & manage their website passwords and includes a random password generator.

## Technology Stack

- **Programming Language:**  Python
- **Library:**  TKinter

## Instructions

1) Fork github repository
2) Clone forked repository onto local machine
3) Open file in an IDE of your choosing (PyCharm Recommended) 
4) Run application
